Rule R1 (Priority):
  IF mcp_value >= 16:    Priority = HIGH → batch
  IF mcp_value <= 15:    Priority = LOW  → single

Rule R2 (Test Type):
  IF test_type == 'regression':  → regression testing
  IF test_type == 'e2e':         → E2E testing
  IF test_type == 'functional':  → basic tests

Rule R3 (Batch):
  IF priority == HIGH:   → batch_process_tickets()
  IF priority <= MID:    → Single processing

Rule R4 (Error):
  IF success == false:   → Handle error + Retry/Fallback
  IF success == true:    → Continue

Rule R5 (Completion):
  IF all_steps_done:     → Generate report → DONE
