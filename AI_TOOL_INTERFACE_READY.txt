📋 4 TOOLS AVAILABLE FOR AI:

1️⃣  route_ticket
    • Route ticket → Determine MCP → Call MCP method
    • Input: ticket_id, mcp_method, count (optional)
    • Output: MCP server name + generated value

2️⃣  determine_mcp_server
    • Check which MCP handles a ticket
    • Input: ticket_id
    • Output: MCP name + reasoning (even/odd check)

3️⃣  call_mcp_even
    • Call random-even-mcp directly
    • Methods: get_random_even, get_random_evens, get_all_evens, validate_even
    • Output: Random numbers, all evens, or validation result

4️⃣  call_mcp_odd
    • Call random-odd-mcp directly
    • Methods: get_random_odd, get_random_odds, get_all_odds, validate_odd
    • Output: Random numbers, all odds, or validation result
