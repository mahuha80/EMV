📋 4 UNIFIED FUNCTIONS (GỌI 1 LẦN - LÀM HẾT):

1️⃣  process_ticket_complete(ticket_id)
    ├─ STEP 1: Route ticket → get MCP value
    ├─ STEP 2: Fetch from Jira
    ├─ STEP 3: Analyze ticket
    └─ STEP 4: Generate test plan

    Gọi một lần → Hoàn thành tất cả!

    from src.ai_processor import AIProcessor
    result = AIProcessor.process_ticket_complete('KAN-7')
    # Bây giờ bạn có: routing, fetch, analysis, test_plan

2️⃣  process_ticket_with_mcp(ticket_id)
    ├─ Auto-route ticket (chẵn → random-even-mcp, lẻ → random-odd-mcp)
    └─ Call MCP → Return value

    from src.ai_processor import AIProcessor
    result = AIProcessor.process_ticket_with_mcp('KAN-7')
    print(result['mcp_value'])  # 17

3️⃣  analyze_and_generate_tests(ticket_id)
    ├─ Fetch ticket
    ├─ Analyze
    └─ Generate test cases

    result = AIProcessor.analyze_and_generate_tests('KAN-7')
    print(result['test_generation']['robot_file_path'])

4️⃣  batch_process_tickets(ticket_ids)
    ├─ Process MANY tickets at once
    └─ Return all results

    result = AIProcessor.batch_process_tickets(['KAN-7', 'KAN-8', 'KAN-9'])
    # Process 3 tickets in one call!
