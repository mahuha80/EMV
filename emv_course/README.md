# 🎓 Giáo Trình EMV cho Lập Trình Viên Android

## 📖 Giới Thiệu

Giáo trình học EMV (Europay-Mastercard-Visa) từ cơ bản đến nâng cao, được thiết kế đặc biệt cho **lập trình viên Android** chưa có kinh nghiệm về EMV.

## 📚 Nội Dung

Giáo trình gồm **10 bài học**:

1. **EMV là gì?** - Khái niệm, lịch sử, so sánh với Magnetic Stripe
2. **Cấu Trúc Thẻ EMV** - Chip architecture, file system, AID
3. **Transaction Flow** - 9 bước xử lý giao dịch chi tiết
4. **APDU Commands** - Cấu trúc lệnh, SELECT, READ RECORD, GPO
5. **EMV Tags & TLV** - TLV encoding, 50+ tags phổ biến
6. **Cryptography** - RSA, DES, SHA, MAC, key hierarchy
7. **Card Authentication** - SDA, DDA, CDA methods
8. **Android NFC & EMV** - Code mẫu đọc thẻ EMV trên Android
9. **Đọc Thẻ Thực Tế** - Practical examples, troubleshooting
10. **Best Practices** - PCI DSS, security, optimization

## 🎯 Lộ Trình Học (5 tuần)

- **Tuần 1 (Bài 1-3):** Hiểu khái niệm EMV, cấu trúc thẻ, transaction flow
- **Tuần 2 (Bài 4-5):** Học APDU commands, EMV tags, TLV encoding
- **Tuần 3 (Bài 6-7):** Cryptography và card authentication
- **Tuần 4 (Bài 8-9):** Lập trình Android NFC, đọc thẻ thực tế
- **Tuần 5 (Bài 10):** Best practices và hoàn thiện dự án
