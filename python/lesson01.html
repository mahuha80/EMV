Biến và kiểu dữ liệu

Python hỗ trợ nhiều kiểu dữ liệu như số nguyên, số thực, chuỗi, danh sách, từ điển, v.v.

# Ví dụ:
x = 10  # số nguyên
y = 3.14  # số thực
z = "Hello"  # chuỗi

Toán tử

Các toán tử cơ bản: +, -, *, /, %, //, **.

# Ví dụ:
a = 5
b = 2
print(a + b)  # 7
print(a ** b)  # 25
