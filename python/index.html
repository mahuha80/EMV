Nội dung: kiểu dữ liệu, function, lớp (class), context manager, exceptions, logging, typing. Giải thích các khái niệm thường dùng trong automation (fixture, teardown).

# Ví dụ: Page Object class đơn giản
class LoginPage:
    def __init__(self, driver):
        self.driver = driver
    def username_field(self):
        return self.driver.find_element_by_id('com.example:id/username')
    def login(self, username, password):
        self.username_field().send_keys(username)
        self.driver.find_element_by_id('com.example:id/password').send_keys(password)
        self.driver.find_element_by_id('com.example:id/login').click()

Bài 3 — Appium basics (Python client)

Giải thích: Desired Capabilities, Session, Remote WebDriver, UiAutomator2 (Android) / XCUITest (iOS).

# Minimal Appium Python example (Android, UiAutomator2)
from appium import webdriver

desired_caps = {
    'platformName': 'Android',
    'platformVersion': '11',
    'deviceName': 'emulator-5554',
    'automationName': 'UiAutomator2',
    'appPackage': 'com.example.myapp',
    'appActivity': '.MainActivity',
    'noReset': True
}

driver = webdriver.Remote('http://localhost:4723/wd/hub', desired_caps)
try:
    el = driver.find_element_by_accessibility_id('Login')
    el.click()
finally:
    driver.quit()

Giải thích dòng chính: automationName chọn engine; noReset giữ trạng thái app; Remote tạo session tới Appium server.

Tham khảo: Appium intro, Desired Capabilities

Bài 4 — Locators, Waits & Common Interactions

Giải thích các locator: resource-id, accessibility id, xpath, class name; sử dụng Explicit Waits tránh flaky tests.

from selenium.webdriver.common.by import By
from selenium.webdriver.support.ui import WebDriverWait
from selenium.webdriver.support import expected_conditions as EC

wait = WebDriverWait(driver, 15)
login_btn = wait.until(EC.element_to_be_clickable((By.ACCESSIBILITY_ID, 'Login')))
login_btn.click()

Tham khảo: Selenium docs (Appium client mirrors many APIs).

Bài 6 — Robot Framework (Automation Orchestration)

Giải thích: Robot Framework là generic test automation framework sử dụng keyword-driven testing. AppiumLibrary là library phổ biến để kết nối Appium.

*** Settings ***
Library    AppiumLibrary

*** Variables ***
${REMOTE}    http://localhost:4723/wd/hub
${PLATFORM}  Android

*** Test Cases ***
Login Test
    Open Application    ${REMOTE}    platformName=${PLATFORM}    deviceName=emulator-5554    appPackage=com.example.myapp    appActivity=.MainActivity
    Click Element    accessibility_id=Login
    Close Application

Tham khảo: Robot Framework, AppiumLibrary

Bài 7 — Test Design & Page Object Pattern

Giải thích cách tổ chức test: Page Objects, fixtures, reusable utilities, locators file, and CI-friendly structure.

# project/
# tests/
#   test_login.py
# pages/
#   login_page.py
# conftest.py (pytest fixtures)

Ví dụ pytest fixture kết hợp Appium session:

import pytest
from appium import webdriver

@pytest.fixture(scope='session')
def driver():
    caps = {...}
    driver = webdriver.Remote('http://localhost:4723/wd/hub', caps)
    yield driver
    driver.quit()

Tham khảo: pytest fixtures

Bài 8 — CI/CD & Real Device Farm

Thiết lập CI (GitHub Actions / Jenkins) để chạy test trên emulator hoặc cloud device farms (BrowserStack, Sauce Labs, Firebase Test Lab).

Ví dụ GitHub Actions job để run pytest tests:

# .github/workflows/android-tests.yml (excerpt)
name: Android Tests
on: [push]
jobs:
  test:
    runs-on: ubuntu-latest
    steps:
      - uses: actions/checkout@v3
      - name: Set up Python
        uses: actions/setup-python@v4
        with:
          python-version: '3.10'
      - name: Install deps
        run: |
          python -m pip install -r requirements.txt
      - name: Run tests
        run: pytest -q

Tham khảo: Docs của BrowserStack, Sauce Labs, Firebase Test Lab, và GitHub Actions
