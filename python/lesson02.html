Câu lệnh điều kiện

Sử dụng if, elif, else để kiểm tra điều kiện.

# Ví dụ:
x = 10
if x > 5:
    print("Lớn hơn 5")
elif x == 5:
    print("Bằng 5")
else:
    print("Nhỏ hơn 5")

Vòng lặp

Sử dụng for và while để lặp qua các phần tử hoặc điều kiện.

# Ví dụ:
for i in range(5):
    print(i)

count = 0
while count < 5:
    print(count)
    count += 1
