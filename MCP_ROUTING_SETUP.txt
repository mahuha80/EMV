🎯 HOW IT WORKS:

┌─ Ticket ID: PROJ-1234
│
├─ STEP 0A: Extract last digit → 4
│
├─ STEP 0B: Check even/odd → EVEN (4 % 2 == 0)
│
├─ STEP 0C: Route to MCP → random-even-mcp
│
└─ STEP 0D: Call MCP → Generate random even number → 18

Then continue with normal pipeline:
  STEP 1: Fetch ticket
  STEP 2: Analyze
  STEP 3: Generate tests
  STEP 4: Run tests
